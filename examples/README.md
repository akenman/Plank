## Contributing Examples

After building a new project with Plank, you can contribute it as an example. Requirements:
1. Complete Phase 1→2→3 full process
2. Phase 3 runtime verification all pass
3. Includes `.arch/BLUEPRINT.md` and `.arch/SUMMARY.md`
4. Zero external dependencies, runnable
